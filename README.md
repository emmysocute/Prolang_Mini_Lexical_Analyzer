# Prolang_Mini_Lexical_Analyzer
Ah project in Programming Languages Concepts and Paradigms 
# Usage

```py
python Mini_Lexical_Analyzer.py -i INPUT [-e EXPECTED]
```

## Example
### run without compare expect output
```py
python Mini_Lexical_Analyzer.py -i testcase/1.in
```

### run with compare expect output
```py
python Mini_Lexical_Analyzer.py -i testcase/1.in -e testcase/1.ans
```
